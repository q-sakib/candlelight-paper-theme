# Candlelight Paper Theme

A warm and calming theme for VSCode, with both light and dark candlelight-inspired variants.

## Features

- ✨ Light and dark versions
- 🎨 Soothing paper and charcoal tones
- ⚙️ Custom settings (opacity, glow)
- 🌐 Theme switching commands

## Commands

- `Switch to Candlelight Paper Light`
- `Switch to Candlelight Paper Dark`

## Configuration

```json
"candlelightTheme.opacity": 0.1,
"candlelightTheme.enableGlow": true
